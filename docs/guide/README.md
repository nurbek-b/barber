# Инструкции Britva Barber

| Для кого | Инструкция |
| --- | --- |
| Владелец и администратор | [admin.md](admin.md) — админка: записи, клиенты, мастера, оплата по QR, магазин, сертификаты, бонусы, маркетинг, финансы, настройки |
| Мастер | [barber.md](barber.md) — Telegram-бот мастера: подключение, записи на день, завершение визита, выплаты |
| Клиент | [client.md](client.md) — запись через Telegram и сайт, перенос и отмена, предоплата, бонусы, отзывы, магазин |

Адреса:

- Админка: https://britva-barber.web.app/admin/
- Онлайн-запись без Telegram: https://britva-barber.web.app/book/
- Приложение для клиентов открывается из Telegram-бота салона кнопкой «Записаться».

Техническая документация для разработчиков — в [README в корне репозитория](../../README.md) и [docs/ARCHITECTURE.md](../ARCHITECTURE.md).
